Issue: Missing document language declaration.

Category: HTML structure / Accessibility.

technologies from reliably identifying the document language.

Issue ID: HTML-02
------------------------------------------------------------

Issue: Incorrect form label association.
Validator message: No actual error reported.
File and location: frontend/src/App.jsx, adoption search form.
Category: Accessibility / Semantic HTML.
Root cause: The label references an identifier that does not
match the corresponding input element.

Before (illustrative):
<label htmlFor="id">Adoption ID</label>
<input id="adoption-id" type="number" />

After (implemented approach):
<label htmlFor="adoption-id">Adoption ID</label>
<input id="adoption-id" type="number" />

Correction: Matched the htmlFor attribute with the input id.

Origin: Preventive implementation example.
Validation result: Rendered React HTML validation not confirmed.

Issue ID: CSS-03
------------------------------------------------------------

Issue: Excessive CSS specificity.
Validator message: No actual error reported.
File and location: frontend/src/App.css, .panel selector.
Category: CSS specificity / Maintainability.
Root cause: Overly specific selectors and unnecessary
!important declarations make CSS difficult to maintain.

Before (illustrative):

    background-color: #ffffff !important;
}

After (implemented approach):

Origin: Preventive implementation example.
Validation result: App.css passed with zero errors.
Note: CSS specificity is a code quality consideration,
not necessarily a syntax validation error.

Issue ID: CSS-04
------------------------------------------------------------

Issue: Missing keyboard focus indicators.
Validator message: No actual error reported.
File and location: frontend/src/App.css, focus selectors.
Category: Accessibility / Keyboard navigation.
Root cause: Removing focus outlines without providing an
alternative makes keyboard navigation difficult.

Before (illustrative):
button:focus {
    outline: none;
}

After (implemented):
a:focus,
input:focus,
button:focus,
.table-container:focus {
    outline: 3px solid #b45309;
    outline-offset: 3px;
}

Correction: Implemented visible focus indicators for
interactive elements.

Origin: Preventive implementation example.
Validation result: App.css passed with zero errors.
Note: Separate accessibility testing is required to verify
keyboard navigation behavior.

------------------------------------------------------------
Issue ID: CSS-05
------------------------------------------------------------

Issue: Nonresponsive layout.
Validator message: No actual error reported.
File and location: frontend/src/App.css, .search-grid
selector and media queries.
Category: Responsive design / CSS optimization.
Root cause: Layouts without appropriate responsive behavior
may become difficult to use on smaller screens.

Before (illustrative):
.search-grid {
    display: flex;
}

After (implemented approach):
.search-grid {
    display: flex;
    flex-wrap: wrap;
}

@media (max-width: 600px) {
    .search-grid {
        display: block;
        margin: 0;
    }

    .panel {
        padding: 1rem;
    }
}

Correction: Implemented flexible layouts and responsive
media queries.

Origin: Preventive implementation example.
Validation result: App.css passed with zero errors.
